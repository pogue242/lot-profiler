# lot-profiler

Tool that combines NYC ZOLA, Population Fact Finder, custom land use analysis tools, and zoning analysis. Currently working on calculating the maximum FAR for each lot in New York City. 

Max FAR values for lots in R6 districts not fronting wide streets but within the 100ft buffer are currently slightly off in 25v4. One- to three-family homes in an R5 district in Boro Park are also slightly off in both 25v4 and 26v2
